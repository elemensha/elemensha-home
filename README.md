# elemensha home

서울·경기 부동산 물건을 조건에 맞게 걸러 알림으로 받고, 내 현금·소득으로
**실제로 살 수 있는지**를 대출 한도부터 매도 시나리오까지 계산하는 앱.

무료 공공 API와 Always Free VM만 쓴다. 운영비 0원.

---

## 이 앱이 하지 않는 것

먼저 이것부터 밝혀둔다. 부동산 앱이 흔히 하는 일 중 여기서 **하지 않는** 것들이다.

- **집값을 예측하지 않는다.** 매도 시나리오의 가격은 전부 사용자가 넣은 가정이거나
  과거 실거래 범위에서 뽑은 값이다. "얼마가 될 것이다"라고 말하지 않고,
  "그 값에 팔린다면 손에 얼마가 남는가"만 계산한다.
- **물건을 추천하거나 순위를 매기지 않는다.** 조건에 맞는 것을 걸러서 보여줄 뿐이다.
- **세무·법률 자문이 아니다.** 대출 한도는 은행 심사에서, 세액은 신고 시점 세법과
  개인 사정에 따라 달라진다.

## 출처 연계

금융·세무 파라미터 45개가 전부 `provenance.py`에 등록돼 있고 **기본 상태가 미검증**이다.
`app/finance/citations.json`이 1차 출처(법령 조항·보도자료 URL·시행일)를 덮어쓴다.

`/api/plan` 응답에는 그 계산에 **실제로 쓰인** 파라미터의 검증 상태가 함께 온다.
검증되지 않은 값으로 계산했으면 앱 화면이 그 사실을 표시한다.

```
검증률 41/45 — 미검증 4건은 화면에 경고로 노출
```

끝내 확인하지 못한 것들(비수도권 스트레스 금리의 2026 하반기 유효성,
재산세 1주택 특례의 적용기한 등)은 숨기지 않고 `unknown`으로 남겨 뒀다.
전체 조사 기록은 [`docs/sources/`](docs/sources/)에 있다.

## 데이터 소스

| 소스 | 용도 | 상태 |
|---|---|---|
| 캠코 온비드 공매 | 신규 물건 알림 | 동작 |
| 국토부 실거래가 | 시세 판정·급매 감지 | 동작 |
| 청약홈 분양공고 | 분양 알림 | 미구현 |
| 법원경매 | — | **넣지 않기로 결정** |

법원경매를 뺀 이유는 [`docs/sources/court-auction-options.md`](docs/sources/court-auction-options.md)에
있다. 요약하면 대법원이 경매정보를 공공데이터가 아닌 '소송기록'으로 규정해 공개 API가 없고,
이용약관 제15조 2호가 가공·영리이용을 금지한다.

### 붙여보고 알게 된 것들

문서만 보고는 알 수 없었고 실제 응답을 받아보고 나서야 드러난 것들이다.

- **실거래가의 직거래를 걸러야 한다.** 직거래는 전체의 5.4%뿐인데, 걸러내기 전
  급매로 잡힌 물건이 **전부** 직거래였다. 가족 간 저가 양도가 섞인다.
- **급매 임계 15%는 영원히 울리지 않는다.** 강남·서초 6개월 정상거래의 실제
  하락폭은 최대 -13%였다. 기본값을 10%로 내렸다.
- **온비드에는 임대 물건이 섞여 있다.** 임대는 최저입찰가가 '임대료'라
  감정가 대비 몇 %로 보인다. API 파라미터로는 못 걸러 받아온 뒤 제외한다.
- **유찰이 쌓인 물건은 싼 게 아니다.** 유찰 24회 -98%짜리가 최상단에 올라왔는데
  전부 생활형숙박시설·오피스텔이었다. 유찰 5회 이상은 경고를 단다.

## 구성

```
server/            FastAPI. Oracle Always Free VM에 systemd 서비스로.
  app/sources/     소스별 어댑터. 전부 Listing 하나로 정규화한다.
  app/finance/     대출 한도·세금·시나리오 계산과 출처 대장.
android/           Compose 앱. 물건 / 자금계획 / 조건 / 설정.
docs/sources/      파라미터 검증 기록. 1차 출처 URL과 조항.
```

## 배포

봇(`elemensha-claude-bot`)과 같은 VM에 두 번째 서비스로 올린다. 한 도메인을
경로로 나눠 쓰며 **봇은 건드리지 않는다**. Caddy 설정은 백업 후 검증을 통과해야만
반영되고, 실패하면 자동으로 되돌린다.

```bash
SSH_KEY=<키경로> bash server/deploy/upload.sh <VM_IP>
```

재실행하면 코드만 갱신되고 `.env`와 SQLite DB는 보존된다.

## 릴리스

태그를 밀면 GitHub Actions가 서명된 APK를 만들어 Releases에 올리고,
앱의 **설정 > 앱 업데이트**가 그것을 받는다.

```bash
git tag -a v0.1.1 -m "설명" && git push origin v0.1.1
```

서명 키는 `android/keystore.properties`(git 제외)나 저장소 Secrets에서 읽는다.
`keystore.properties.example`을 복사해 채울 것.
